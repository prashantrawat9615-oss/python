# School and Shop Management System

This program is organized into separate Python modules:

```text
expense_attendance_grading_billing/
|-- main.py        # Entry point and main menu
|-- validators.py  # Validated console input helpers
|-- expenses.py    # Expense functions
|-- attendance.py # Attendance functions
|-- grading.py    # Grade report functions
|-- billing.py    # Invoice functions
|-- reports.py    # Combined system report
`-- README.md     # How to run
```

## Run

Open a terminal in this directory and run:

```bash
python main.py
```

Data is kept in memory while the program runs and is reset when it exits.
